# 艾联猫 · ailinkcat

> PC 端主题包设计器 · 硬件监控联动 · 多端协同工具

艾联猫是一款面向 PC 与移动端联动的效率工具，提供主题包设计、硬件监控、媒体控制、快捷面板等功能。您可以通过 PC 端编辑器创建个性化主题包，实时推送到手机端使用。

---

## 功能特性

### 🎨 主题包编辑器
- **15 种组件**：按钮、表盘、便签、图片、文本、形状、网页视图、媒体控制、系统监控、快捷面板、应用启动、时钟、日期、日历、图标
- **三种布局**：网格（grid）、列表（list）、自由（free）
- **AI 辅助设计**：通过自然语言操作编辑器
- **资源去重**：Base64 图片自动提取为文件，多页面复用只存一份
- **主题包导出**：打包为 `.alc` 格式，一键分享

### 📡 多端联动
- **WebSocket 实时推送**：PC 端编辑的主题包实时推送到手机端
- **硬件监控**：CPU、内存、磁盘、网络用量实时同步
- **媒体控制**：QQ 音乐等播放器状态同步与控制

### 📦 主题市场
- 浏览、下载、评分其他用户分享的主题包
- 上传自己的主题包到市场审核
- 版本历史、收藏管理

### 🔌 设备管理
- 本地 WebSocket 服务器
- 二维码扫码连接
- 已登录设备列表

### 👤 用户系统
- 账号注册/登录（邮箱验证码防护）
- GitHub OAuth 一键登录
- 积分中心（签到、兑换商城、排行榜）
- 会员体系（云盘、极速下载等权益）
- 工单系统（问题反馈与回复）
- 邀请好友

### ☁️ 云服务
- 主题云备份
- 个人资料管理
- 通知中心

## 快速开始

### 系统要求

| 平台 | 要求 |
|------|------|
| Windows | Windows 10 1809+ / Windows 11 |
| macOS | macOS 10.15+ |
| 内存 | ≥ 4GB |
| 磁盘 | ≥ 500MB |

### 下载安装

从 [Releases](https://github.com/mosder66/alinkcat/releases) 下载最新安装包：

| 平台 | 文件 |
|------|------|
| Windows | `艾联猫_Setup_x.x.x.exe` 或 `.msi` |
| macOS | `艾联猫_x.x.x.dmg` |
