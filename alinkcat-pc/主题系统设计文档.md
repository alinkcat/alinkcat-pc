# 艾联猫（ailinkcat）主题系统设计文档

> 本文档用于开源主题设计思路，并作为后端开发主题文档页面的依据。
> 描述 PC 端主题包（`.alc`）的完整数据模型、组件规范、编辑器、打包与推送协议。

---

## 一、主题系统概述

主题系统是艾联猫的核心功能，负责定义"手机端如何展示信息与交互"。一个**主题包（Theme）**由多个**页面（Page）**组成，每个页面包含若干**组件（Widget）**，组件承载具体的内容与功能。

### 1.1 核心概念

| 概念 | 说明 |
|------|------|
| **主题包（Theme）** | 一个 `.alc` 包，包含 `theme.json` 元数据 + 资源文件（图片、图标等） |
| **页面（Page）** | 主题中的一个屏幕，有独立的布局与背景 |
| **布局（Layout）** | 页面的排布方式：网格（grid）/ 列表（list）/ 自由（free） |
| **组件（Widget）** | 页面上的最小功能单元，共 15 种类型 |
| **资源（Asset）** | 组件引用的图片/图标文件，统一定期去重 |

### 1.2 数据流向

```
PC 编辑器（构建主题）→ 保存为 theme.json + 资源 → 打包 .alc
                                            ↓
                               WebSocket 推送协议（分块 + 确认）
                                            ↓
                          手机端接收 → 解压 → 渲染主题
```

## 二、主题包文件结构

### 2.1 存储目录

主题存放在 `~/.ilinkcat/themes/{themeId}/` 下：

```
~/.ilinkcat/themes/
├── {themeId}/
│   ├── theme.json          # 主题元数据（核心）
│   ├── cover.png           # 主题封面（可选）
│   ├── assets/             # 通用图片资源
│   │   └── {hash}.png
│   └── icons/              # SVG 图标资源
│       └── {hash}.svg
└── ...
```

顶层 `~/.ilinkcat/config.json` 保存应用配置（当前激活主题、命令白名单）。

### 2.2 打包格式（.alc）

`.alc`（Alink Cat Zip）本质是一个 **ZIP 压缩包**，使用 Deflated 压缩，内含 `theme.json` 与全部资源文件。打包后用 **Base64** 编码传输。

## 三、数据模型（JSON Schema）

### 3.1 ThemeMeta（主题元数据）

```json
{
  "id": "perf-dashboard",
  "name": "性能仪表盘",
  "version": "1.0.0",
  "author": "艾联猫",
  "description": "实时监控系统性能",
  "preview": "预览图路径",
  "source": "local|downloaded|market",
  "market_id": "市场ID",
  "downloaded_at": "下载时间",
  "pages": []
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | ✅ | 主题唯一标识，不能包含 `/`、`\`、`..` |
| `name` | string | ✅ | 主题名称 |
| `version` | string | ✅ | 版本号 |
| `author` | string | ✅ | 作者 |
| `description` | string | ❌ | 描述 |
| `preview` | string | ❌ | 预览图 |
| `source` | string | ❌ | 来源：`local`/`downloaded`/`market` |
| `market_id` | string | ❌ | 市场 ID |
| `downloaded_at` | string | ❌ | 下载时间 |
| `pages` | array | ✅ | 页面列表，至少 1 个 |

### 3.2 PageDefinition（页面）

```json
{
  "id": "page-1",
  "label": "主页",
  "layout": {
    "type": "grid",
    "columns": 4,
    "rows": 6,
    "backgroundColor": "#ffffff",
    "backgroundImage": "assets/bg.png",
    "backgroundMode": "cover",
    "backgroundOpacity": 100
  },
  "widgets": []
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 页面唯一标识 |
| `label` | string | 页面名称 |
| `layout.type` | string | 布局类型：`grid`/`list`/`free` |
| `layout.columns` | number | 网格列数（grid 布局） |
| `layout.rows` | number | 网格行数（grid 布局） |
| `backgroundColor` | string | 页面背景色 |
| `backgroundImage` | string | 页面背景图（路径或 data URL） |
| `backgroundMode` | string | `cover`/`contain`/`stretch`/`repeat` |
| `backgroundOpacity` | number | 背景透明度 0-100 |
| `widgets` | array | 组件列表 |

### 3.3 WidgetDefinition（组件通用字段）

所有组件共享以下字段：

```json
{
  "id": "w-xxx",
  "type": "button",
  "label": "快捷键",
  "gridCol": 0, "gridRow": 0, "gridW": 1, "gridH": 1,
  "freeX": 10, "freeY": 10, "freeW": 30, "freeH": 15,
  "borderRadius": 6,
  "backgroundColor": "#f0f2f5",
  "backgroundOpacity": 100,
  "textColor": "#333333",
  "fontSize": 12,
  "fontWeight": "normal"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 组件唯一标识 |
| `type` | string | 组件类型（见第四章） |
| `label` | string | 显示名称 |
| `gridCol` / `gridRow` | number | 网格布局中的位置 |
| `gridW` / `gridH` | number | 网格布局中的尺寸 |
| `freeX` / `freeY` | number | 自由布局中的位置（百分比） |
| `freeW` / `freeH` | number | 自由布局中的尺寸（百分比） |
| `borderRadius` | number | 圆角 |
| `backgroundColor` | string | 背景色 |
| `backgroundOpacity` | number | 背景透明度 0-100 |
| `textColor` | string | 文字颜色 |
| `fontSize` | number | 字号 |
| `fontWeight` | string | `normal`/`bold`/`bolder` |

> 各组件通过 `extra` 字段（展平）承载各自特色的属性。

## 四、组件（Widget）规范

共 **15 种组件**，按 `type` 区分。以下为每种组件的专属属性定义。

### 4.1 按钮（button）

用于触发快捷操作（键盘、应用启动等）。

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `icon` | string | 🔘 | 图标（Emoji 或 SVG） |
| `action.type` | string | keyboard | 动作类型：`keyboard`/`launcher`/`command` |
| `action.keys` | array | [] | 键盘按键组合 |

### 4.2 数据表盘（gauge）

展示单项数据（如 CPU 使用率）。

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `dataSource` | string | system.cpu.usage | 数据源（订阅路径） |
| `unit` | string | % | 单位 |
| `gaugeStyle` | string | ring | 样式：`ring`（环形）/`number`（数字）/`bar`（条形） |
| `minValue` / `maxValue` | number | 0 / 100 | 量程 |
| `ringColorLow` | string | #52c41a | 低值颜色 |
| `ringColorMid` | string | #faad14 | 中值颜色 |
| `ringColorHigh` | string | #ff4d4f | 高值颜色 |
| `ringWidth` | number | 3 | 环宽 |

### 4.3 便签列表（snippet-list）

展示快捷输入内容（客服话术等）。

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `snippets` | array | [] | 便签数组 `{id, label, content}` |
| `mode` | string | note | 模式：`note` 等 |

### 4.4 图片（image）

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `src` | string | '' | 图片路径或 data URL |
| `objectFit` | string | cover | 适配：`cover`/`contain`/`fill` |

### 4.5 文本标签（text）

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `content` | string | 双击编辑文字 | 文本内容 |
| `textAlign` | string | left | 对齐：`left`/`center`/`right` |
| `color` | string | #333333 | 文字颜色 |
| `padding` | number | 4 | 内边距 |

### 4.6 形状（shape）

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `shapeType` | string | rect | `rect`/`circle`/`line` 等 |
| `fillType` | string | solid | `solid`/`gradient`/`none` |
| `fillColor` | string | #d9d9d9 | 填充色 |
| `gradientStart` | string | #4F6EF7 | 渐变起色 |

| `borderColor` | string | transparent | 边框色 |
| `borderWidth` | number | 0 | 边框宽 |
| `opacity` | number | 100 | 不透明度 |

### 4.7 网页视图（webview）

支持网页、RSS、JSON 三类数据源及预设。

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|

## 五、布局模式

### 5.1 网格布局（grid）

- 页面划分为 `columns × rows` 网格
- 组件通过 `gridCol`/`gridRow`/`gridW`/`gridH` 定位
- 适合规则排布

### 5.2 列表布局（list）

- 组件纵向排列，每个组件占一行
- 适合信息流（便签、RSS、媒体）

### 5.3 自由布局（free）

- 组件通过 `freeX`/`freeY`/`freeW`/`freeH`（百分比）精确定位
- 适合精细设计，支持吸附对齐

## 七、资源管理（数据复用）

### 7.1 资源去重

保存主题时自动扫描所有组件 `extra` 字段中的 `src`/`icon`/`backgroundImage`，将 **Base64 data URL 提取为独立文件**并去重：

```
保存前：theme.json 中嵌入 data:image/png;base64,... × N 次
保存后：assets/{hash}.png（仅一份）+ theme.json 引用路径
```

- 相同内容的图片只存一份
- SVG 存入 `icons/`，其他图片存入 `assets/`
- 文件名 = 内容 hash + 扩展名，天然去重

### 7.2 孤儿资源清理

保存时 `cleanup_orphaned_assets` 删除不再被 theme.json 引用的旧资源，避免文件膨胀。

## 八、主题打包与推送协议

### 8.1 打包（.alc）

1. 读取主题目录 + `theme.json`
2. 用 `zip::ZipWriter` 递归压缩，Deflated 算法
3. Base64 编码，附带 SHA-256 `hash` 校验

### 8.2 WebSocket 推送协议（JSON-RPC 2.0）

PC 通过 WebSocket 将 `.alc` 分块推送到手机端。

**消息方法：**

| 方法 | params | 说明 |
|------|--------|------|
| `theme.push.start` | `themeId`、`name`、`version`、`size`、`totalChunks`、`hash` | 推送开始 |
| `theme.push.chunk` | `themeId`、`chunkIndex`、`data`(base64)、`isLast` | 推送数据块 |
| `theme.push.complete` | `themeId`、`status` | 推送完成 |
| `theme.push.cancel` | `themeId`、`reason` | 推送取消 |

**分块参数：**
- 每块 **64KB**（`CHUNK_SIZE`）
- 开始握手：等待手机端回复 `ready`/`busy`/`reject`，10 秒超时，busy 时 3 秒重试，最多 5 次
- 每块：8 秒超时，最多重试 3 次
- 支持断点续传（`start_chunk` 参数）

**手机端接收流程：**
1. 收到 `theme.push.start` → 弹窗确认 → 回复 `ready`/`busy`/`reject`
2. 接收 64KB 数据块，逐块确认
3. 收到最后一块/`complete` → 重组 Base64 → 解压 `.alc` → 校验 SHA-256 → 导入渲染

## 十一、主题验证规则

导入/保存时校验：

1. `id` 非空，不能包含 `/`、`\`、`..`
2. `name` 非空
3. 至少包含 1 个页面
4. 页面 `id` 非空
5. 布局类型必须在 `grid`/`list`/`free` 中
6. 组件类型必须在 15 种合法类型中

---

## 十二、数据推送（运行时）

激活主题后，PC 通过 WebSocket 持续推送实时数据：

- **系统监控数据**：CPU、内存、磁盘、网络、运行时长（每 2 秒）
- **媒体状态**：歌曲名、歌手、播放状态、进度（每 2 秒）
- 通过 `monitor.update` / `media.update` 方法推送，支持按需订阅（`theme.enter`/`theme.leave`）
