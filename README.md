# 艾联猫 · ailinkcat — PC 端

> 主题包设计器 · 硬件监控联动 · 多端协同工具

艾联猫（ailinkcat）是一套 PC 与 Android 联动的效率工具：**PC 端负责制作、管理与推送主题包**，Android 端负责接收、渲染与交互。本仓库是 PC 端（Tauri 2 桌面应用）。

无论是系统监控面板、快捷控制中心、媒体播放器，还是自定义桌面布局，都可以用编辑器拖出来，再通过局域网实时推送到手机。

---

## ✨ 功能特性

### 🎨 主题包编辑器

- **15 种组件**：按钮、数据表盘、便签、图片、文本、形状、网页视图、媒体控制、系统监控、快捷面板、应用启动、时钟、日期、日历、图标
- **三种布局**：网格（Grid）、列表（List）、自由（Free）
- **AI 辅助设计**：自然语言操控编辑器（8 种指令），支持拖入图片自动识别
- **资源自动去重**：Base64 图片自动提取为文件，跨页面复用只存一份
- **主题包导出**：打包为 `.alc` 格式，一键分享
- **文件管理器**：树形结构浏览主题包资源
- 横竖屏切换、实时预览、多层撤销

### 📡 多端联动

- **WebSocket 实时推送**：PC 编辑的主题包实时推送到 Android 端（分块传输 + SHA-256 校验 + 断点续传）
- **硬件监控**：CPU / 内存 / 磁盘 / 网络用量实时同步
- **媒体控制**：QQ 音乐等播放器状态同步与控制
- **快捷操作**：应用启动、快捷面板指令下发

### 🛒 主题市场

- 浏览、下载、评分其他用户分享的主题包
- 上传自己的作品，提交审核后上架
- 收藏管理、版本历史

### 👤 用户系统

- 账号注册 / 登录（邮箱验证码防滥用）
- GitHub OAuth 一键登录
- 积分中心（每日签到、兑换商城、排行榜）
- 会员体系（高级 / 专业两档，权益对比见下文）
- 工单系统（问题反馈与回复）
- 邀请好友（双方积分奖励）

### ☁️ 云服务

- **主题云备份**：上传 / 恢复 / 删除，随时取回
- **天气服务**：一键申请天气 API Key（ALM- 格式），填入 Android 端即用，无需自行注册第三方天气 API
- **通知中心**：审核、系统、积分通知
- **个人资料**：修改密码、GitHub 绑定

### 🔧 系统能力

- 版本自动检查（启动检测 + 定时轮询），支持强制更新
- 全局错误兜底，崩溃自动恢复
- Token 过期强制重新登录
- 诊断日志加密导出
- 深色 / 浅色主题切换
- 内置服务条款页面

## 💻 安装

### 系统要求

| 平台 | 要求 |
|------|------|
| Windows | Windows 10 1809+ / Windows 11 |
| macOS | macOS 10.15+ |
| 内存 | ≥ 4GB |
| 磁盘 | ≥ 500MB |

### 下载安装

前往 [GitHub Releases](https://github.com/alinkcat/alinkcat-pc/releases) 下载对应平台的安装包：

| 平台 | 文件 |
|------|------|
| Windows | `.exe` 或 `.msi` |
| macOS | `.dmg`（Apple Silicon / Intel） |

> Windows 首次运行如出现 SmartScreen 提示，选择「更多信息 → 仍要运行」即可。

### 从源码构建

```bash
# 前置要求：Node.js 20+、pnpm 9+、Rust stable
# macOS 需先安装 Xcode Command Line Tools：xcode-select --install
# Windows 需 WebView2（Win10/11 一般自带）与 Microsoft C++ Build Tools
pnpm install
pnpm tauri dev     # 开发模式
pnpm tauri build   # 打包
```

> 仓库通过 `.gitattributes` 统一行尾为 LF，跨平台克隆开发不会出现 CRLF 警告或行尾漂移。

## 🚀 快速上手

1. **安装并启动**，首次启动会展示引导页；
2. **注册账号**（见下文「云服务」），或先以游客身份浏览本地功能；
3. **制作主题**：进入「编辑器」→ 拖入组件、调整样式 → 保存；
4. **推送手机**：Android 端安装艾联猫 App，与 PC 处于同一局域网，扫码连接后即可把主题包推送到手机；
5. **云备份**：登录后进入「我的云」上传主题，换机随时恢复。

## ☁️ 云服务使用说明

### 注册账号

应用内「登录 / 注册」页提供两种方式：

- **邮箱注册**：填写用户名（3–50 字符）、密码（≥6 位）、邮箱，获取验证码后提交（可留空手机号/昵称）；
- **GitHub 登录**：一键授权，自动创建账号。

注册时需勾选同意应用内《服务条款》。

### 登录

- 用户名 + 密码；
- GitHub 一键登录；
- Token 过期后应用会弹出重新登录窗口，不会静默丢会话。

### 会员中心

「会员中心」页可查看当前等级、购买会员、卡密兑换、申请天气 Key。权益按 免费 / 高级会员 / 专业会员 三档区分（具体数值以应用内「权益对比」弹窗为准）：

| 权益 | 免费 | 高级会员 | 专业会员 |
|------|:---:|:---:|:---:|
| 云盘空间 | 基础额度 | 更大空间 | 更大空间 |
| 单文件 / 文件数上限 | 基础 | 提升 | 提升 |
| AI 对话（/月） | — | 限额 | 更多 |
| 免广告 | — | ✅ | ✅ |
| 极速下载 | — | ✅ | ✅ |
| 自定义主题 | — | ✅ | ✅ |
| 数据导出 / 优先客服 / 多设备同步 | — | ✅ | ✅ |

获取方式：

- **直接购买**：生成订单后按提示支付；
- **积分兑换**：积分中心签到、完成任务积累积分，可兑换会员时长；
- **卡密兑换**：输入卡密（形如 `ALCX7K2M9F4R1Q3`）立即开通。

### 天气 API Key

PC 端免去自行注册第三方天气服务：

1. 进入「会员中心 → 天气服务」；
2. 点击 **申请 Key**，得到 `ALM-` 开头的密钥（**仅展示一次**，请立即复制保存）；
3. 把 Key 填入 Android 端天气控件即可使用，无需登录；
4. Key 遗失可在会员中心 **重置**（旧 Key 立即作废）。

> 每日额度按申请时的会员等级固化，用于防止滥用。

### 主题云备份

「我的云」页面支持：上传本地主题包（自动打包为 `.alc`）、查看云盘空间用量、下载恢复、删除。云盘空间受会员等级影响。

### 工单与通知

遇到问题可进入「工单中心」提交反馈（附诊断日志更高效）；审核结果、系统公告、积分变动会出现在「通知中心」。

## 🧱 技术栈与目录

| 层 | 技术 |
|---|---|
| 前端 | React 19 + TypeScript + Vite 7 + Ant Design 6 + zustand + i18next |
| 桌面壳 | Tauri 2（Rust） |
| 本地服务 | Rust 侧 WebSocket 服务器（端口 9527）+ 硬件监控 / 媒体控制 / 天气 / RSS / B 站接口 |
| 通信协议 | JSON-RPC 2.0 over WebSocket（与 Android 端互通） |
| 云端后端 | 独立 Spring Boot 服务（**不开源**，见下方声明） |

```
├── src/               # React 前端
│   ├── api/           # 云端 API 客户端
│   ├── components/    # 通用组件
│   ├── hooks/         # 推送、AI、WebSocket 等 hook
│   ├── i18n/          # 国际化（zh-CN / en-US）
│   ├── pages/         # 页面（编辑器 / 市场 / 会员 / 云盘 / 设置…）
│   ├── store/         # zustand 状态
│   ├── templates/     # 内置主题模板
│   └── utils/         # 工具
├── src-tauri/         # Rust 后端
│   └── src/
│       ├── action/    # 快捷操作执行器（键盘模拟 / 应用启动）
│       ├── commands/  # Tauri 命令
│       ├── monitor/   # 硬件监控采集（CPU / 内存 / 磁盘 / 网络）
│       ├── services/  # 天气 / 媒体 / 启动器 / RSS / OAuth 等
│       ├── websocket/ # 局域网推送服务
│       └── theme/     # 主题包读写与打包
└── public/            # 静态资源
```
