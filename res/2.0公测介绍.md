# 艾联猫（ailinkcat）2.0 公测版 · 功能介绍

> 让灵感，2 分钟落地。
> PC 端主题设计器 + Android 移动端渲染引擎 · 多端实时联动

---

## 一、这是什么？

艾联猫是一款 **PC 与手机联动的个性化主题工具**。你在 PC 上像搭积木一样设计一个桌面主题，一键实时推送到 Android 手机上，手机桌面立刻变成你专属的样子——可以显示天气、时钟、系统监控、媒体控制、应用快捷入口等动态组件。

**它解决的问题很简单：** 想要一个好看又实用的个性化桌面，但不想改代码、不想装各种乱七八糟的启动器。

## 二、2.0 公测亮点

### ✨ 亮点一：AI 一句话，生成整页主题
在编辑器里输入一句描述，比如"做一个赛博朋克风格的监控桌面"，AI 就能生成**一整页可编辑的主题**——控件布局、配色、数据源一步到位。生成后你依然可以像普通主题一样自由微调。

> 附：AI 指令助手同时支持细粒度操作（添加 / 删除 / 移动控件、改布局、改背景等）。

### 📦 亮点二：内置模板库，2 分钟做出第一个主题
2.0 内置了 **21 套精心打磨的高质量模板**：游戏风、极简、赛博朋克、天气、时钟、监控桌面、音乐墙、自然、商务、户外运动…… 从模板开始，改改文字和配色，你的第一个主题就诞生了。

### 🖼️ 亮点三：GIF 动态组件
主题控件与背景支持 **GIF 动画**，让静态桌面"活"起来——动态壁纸、呼吸灯效、加载动画都能轻松实现。

### 🎛️ 亮点四：更专业的编辑体验
- **全键盘操作**：`Delete` 删除、`Ctrl+C / Ctrl+V` 复制粘贴、`Ctrl+D` 快速复制、方向键微调
- **图层控制**：自由布局下支持置顶 / 置底 / 上移 / 下移
- **统一撤销**：AI 操作与手动编辑共享同一套撤销历史，`Ctrl+Z` 回退到任意一步
- **自动保存**：编辑过程自动存档，意外退出也能一键恢复

### 📤 亮点五：一键分享，让作品被看见
完成主题后，一键生成**分享海报**和**预览页**。发到朋友圈、群聊，好友无需安装即可预览你的作品。

### 🛡️ 亮点六：更稳定、更可靠
- 崩溃自动上报（Sentry），问题更快被修复
- 推送支持**断点续传与失败自动重试**，大主题包也能稳稳送达
- 界面支持**中英双语**，设置中一键切换

## 四、怎么用？

### 第一步：安装

| 端 | 安装方式 |
|---|---|
| **PC 编辑器** | 下载安装包（Windows），运行即可 |
| **Android 端** | 安装 APK（公测版） |

### 第二步：快速开始
1. PC 端打开编辑器 → **从模板开始**，选一套喜欢的模板
2. 改文字、配色，或用 AI 一句话生成整页
3. 点「保存」并**推送到手机**
4. 手机端扫描 / 确认配对 → 主题立即生效

### 第三步：进阶玩法
- 用 **快捷面板 + 应用启动** 把常用 App 放上桌面
- 挂 **系统监控 + 天气 + 时钟**，桌面就是一块信息面板
- 用 **GIF 组件** 做动态背景
- 完成后**生成分享海报**，把作品发给朋友
