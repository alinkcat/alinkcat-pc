# 主题包结构规范（.alc）

> 依据双端实际解析代码整理（2026-10-04）：PC `manager.rs validate_theme` + `editorToThemeMeta`，Android `Theme.kt` / `Widget.kt` / 各渲染器。
> 用途：批量制作起始资源（模板主题包）时的唯一权威参考。字段名以 **PC 端写法为准**，Android 端已做别名兼容。

## 一、包文件构成

`.alc` = 标准 ZIP，内容：

```
push-test.alc
├── theme.json          # 必需，主题描述（唯一必须文件）
├── cover.png           # 可选，封面（缺失时 PC 推送自动生成占位图）
├── assets/             # 可选，位图资源（PNG/JPG/GIF）
│   └── {sha256}.png    # PC 保存时按内容哈希命名，theme.json 内以相对路径引用
└── icons/              # 可选，SVG 图标
    └── {sha256}.svg
```

- 手机安装位置：`files/themes/{themeId}/`（解压，含 zip-slip/炸弹防护）
- `meta.json` 是手机端推送元数据，**不属于 .alc**，不要打进去
- 资源引用一律**相对路径**（`assets/xxx.png`）；绝对路径与 `..` 会被手机端拒绝
- PC 导入校验：id 非空且不含 `/ \ ..`、name 非空、≥1 个 page、page.id 非空、layout.type ∈ {grid, list, free}、widget.type ∈ 18 种白名单

## 二、theme.json 顶层结构

```json
{
  "id": "my-theme",                  // 必需，唯一，禁止 / \ ..
  "name": "我的主题",                 // 必需，列表展示名
  "version": "1.0.0",                // 建议语义化
  "author": "作者",
  "description": "一句话描述",
  "orientation": "landscape",        // landscape | portrait（手机按此定横竖屏）
  "pages": [ /* 至少 1 页 */ ]
}
```

## 三、Page 结构

```json
{
  "id": "p1",                        // 必需，页内唯一
  "label": "主页",                    // 页面切换器显示名
  "layout": {
    "type": "grid",                  // grid | free（list 会被手机当 grid）
    "columns": 4,                    // grid 列数
    "rows": 6,                       // grid 行数
    "backgroundColor": "#101024",    // 页面底色
    "backgroundImage": "assets/xxx.jpg",  // 可选，底图
    "backgroundMode": "cover",       // cover | contain | stretch | tile
    "backgroundOpacity": 100         // 0-100
  },
  "widgets": [ /* 见下 */ ]
}
```

grid 布局：控件按 `gridCol/gridRow/gridW/gridH` 定位，越界部分手机端会被钳回。
free 布局：控件按 `freeX/freeY/freeW/freeH` 百分比（0-100）定位，同样会被钳制。

## 四、Widget 公共字段（所有类型通用）

```json
{
  "id": "w-clock",                   // 全主题唯一
  "type": "clock",                   // 18 种之一（见下）
  "label": "时钟",                    // 多数控件的标题/说明文字
  "gridCol": 0, "gridRow": 0,        // grid 定位（0 起）
  "gridW": 2, "gridH": 1,            // grid 跨度，col+span ≤ columns
  "freeX": 5, "freeY": 5,            // free 定位（百分比）
  "freeW": 90, "freeH": 35,
  "zIndex": 0,
  "backgroundColor": "#16213e",      // 控件底色，transparent 可用
  "backgroundOpacity": 100,          // 0-100
  "textColor": "#ffffff",
  "fontSize": 12,
  "fontWeight": "normal",            // normal | bold | bolder
  "borderRadius": 8,
  "clickAction": { "type": "...", "content": "..." }   // 可选，见 §6
}
```

## 五、18 种控件与专属字段

### 1. clock 时钟
`format24h`(bool), `showSeconds`(bool), `showAmpm`(bool), `clockDisplay`("digital"|"analog"), `showWeekday`(bool), `tickMarks`, `showNumbers`, `handStyle`("classic"|"modern"|"thin"), `faceColor`, `handColor`

### 2. date 日期
`dateFormat`(如 "YYYY年MM月DD日 星期X"), `showLunar`(bool，农历)

### 3. gauge 仪表
`dataSource`(见 §7), `unit`("%"), `gaugeStyle`("ring"|"number"|"bar"), `minValue`, `maxValue`, `ringColorLow`(<50%), `ringColorMid`(<80%), `ringColorHigh`(≥80%), `ringWidth`(**1-6**，手机按 1:2 折算 dp，超界会被钳制)
注意：`dataSource` 数值会归一化到 min-max 区间

### 4. battery 电池
`batteryStyle`("bar"|"ring"|"number"), `showLevel`, `showCharging`, `showTemp`, `barColor`, `lowColor`, `lowThreshold`(0-100), `dataSource`("system.battery.level")

### 5. system-monitor 系统监控
`showCPU`, `showMemory`, `showDisk`, `showNetwork`（注意 CPU 大写，写在控件顶层）
显示：CPU/内存/磁盘占用条 + 上传/下载速率。建议占满整行（gridCol 0 + gridW = columns）

### 6. media-control 媒体控制
`displayMode`("always"|"playing_only"), `showCover`(bool), `showProgress`(bool)
自动展示：封面/标题/歌手/进度（PC 实时推送）。渲染分三档：大格全功能、中格隐藏音量、小格仅播放/切歌键

### 7. webview 网页/数据
`url`(网页模式), `displayMode`("webpage"|"rss"|"json"), `rssUrl`(rss 模式), `jsonUrl`(json 模式), `refreshInterval`(秒), `titleField`/`descField`/`timeField`/`linkField`(json 字段映射), `headers`(对象)
安全限制：仅 http/https

### 8. weather 天气
`url`(自建 API，模板含 `${city}`/`${apiKey}` 占位), `preset`("weather"), `city`, `apiKey`, `unit`("c"), `refreshHours`, `requestMethod`/`requestUrl`/`requestHeaders`, `responseMapping`(字段映射对象), `extraParams`
未配 Key 时显示引导文案

### 9. image 图片
`src`(相对路径 assets/xxx), `objectFit`("cover"|"contain"|"stretch"), `borderRadius`, `clickAction`

### 10. text 文本
`content`(正文), `color`(文字色), `textAlign`("left"|"center"|"right"), `padding`

### 11. shape 形状
`shapeType`("rect"|"rounded-rect"|"circle"|"triangle"|"diamond"), `fillType`("solid"|"gradient"), `fillColor`, `gradientStart`, `gradientEnd`, `gradientAngle`(0-360), `borderColor`, `borderWidth`(0-10), `borderRadius`

### 12. button 按钮
`icon`(emoji), `action`({type:"keyboard", keys:[]} 等，经 action.execute 下发）

### 13. snippet-list 便签/清单
`snippets`([{"id","label","content"}]), `mode`("note")
点击便签 = 内容注入 PC 光标处

### 14. card 卡片
`cardTitle`, `cardDesc`, `cardImage`, `cardImagePosition`("top"), `cardTags`[], `cardFooter`

### 15. quick-action 快捷面板
`columns`, `rows`, `cells`([{"type":"launcher","name","path"} 或 {"type":"snippet","title","snippets":[]}])
launcher cell 的 path 为 PC 可执行名（如 "calc"），点击远程启动

### 16. launcher 应用启动
`name`, `path`(PC 可执行名/路径), `icon`(emoji)
点击 = PC 启动该程序

### 17. calendar 日历
`viewMode`("month"), `highlightToday`(bool)（手机端目前主要消费配色字段）

### 18. icon 图标（保留型，手机端按 button 处理）

## 六、clickAction 动作类型

| type | content | 行为 |
|---|---|---|
| `switch_page` | 目标页索引（"1"） | 手机端切页 |
| `toggle_widget` | 目标 widgetId | 切换控件可见性 |
| `open_link` | URL（仅 http/https） | 手机浏览器打开 |
| `system_command` | 命令描述 | 经 action.execute 下发 PC |
| `launcher_open` | PC 程序路径/名 | PC 启动程序 |
| `media_play_pause` / `media_next` / `media_previous` / `media_volume_set`(content=0-100) | — | 媒体控制 |

## 七、数据源（gauge/system-monitor 用）

| dataSource | 含义 |
|---|---|
| system.cpu.usage | CPU % |
| system.memory.usage | 内存 % |
| system.disk.usage | 磁盘 % |
| system.network.upload / download | 网速 KB/s |
| system.uptime | 开机秒数 |
| system.battery.level / temperature | 电量 / 温度 |

## 八、制作注意事项（踩坑总结）

1. **ringWidth ≤ 6**；grid 跨度不得越界（`gridCol + gridW ≤ columns`，行同理）——越界会被钳制，PC 预览与手机可能不一致
2. 系统监控卡建议 `gridCol: 0, gridW: columns` 整行铺放
3. 媒体组件过小（约 <170dp 宽）会自动降级为迷你布局，标题会被隐藏——重要信息别只放标题
4. 天气/需要数据的控件依赖配置（天气 Key），模板里放一个即可，别满屏都是
5. 主题默认内容（便签文字、卡片描述等）属于"数据"，可直接中文；面向双语用户时做成两套模板
6. id 命名建议前缀化（`w-`、`p-`、`s-`），生成器批量产出时避免碰撞
7. 单页控件数量建议 ≤ 12，grid 跨度用 2 的倍数更整齐
8. 打包用标准 ZIP（.alc 后缀），theme.json 必须在包根目录
