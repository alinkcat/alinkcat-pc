# ailinkcat — Public Beta Announcement

> Version: v0.1.1 | Date: 2026-08-16

---

## 🎉 About ailinkcat

ailinkcat is a PC-to-mobile productivity tool focused on **theme design**, **hardware monitoring**, and **multi-device control**.

Use the PC editor to create personalized theme packages and push them to your phone in real time. System monitoring dashboards, quick-control centers, media players, or custom desktop layouts — ailinkcat handles it all.

---

## ✨ Core Features

### 🎨 Theme Editor
- **15 widget types**: button, gauge, snippet list, image, text, shape, webview, media control, system monitor, quick-action grid, app launcher, clock, date, calendar, icon
- **Three layout modes**: Grid, List, Free
- **AI-assisted design**: drive the editor with natural language; drop in images for auto-recognition
- **Asset deduplication**: images auto-extracted to files; cross-page reuse stores only one copy
- **File manager**: tree-view browser for theme assets
- Orientation toggle, live preview, multi-level undo

### 📡 Multi-Device Sync
- **WebSocket real-time push**: PC-edited themes pushed to phone in real time
- **Hardware monitoring**: CPU / memory / disk / network synced live
- **Media control**: QQ Music and other player status sync

### 🛒 Theme Marketplace
- Browse, download, and rate themes shared by other users
- Upload your work for marketplace review
- Favorites management, version history

### 👤 User System
- Account registration / login (email verification protection)
- GitHub OAuth one-click login
- Points center (check-in, redemption shop, leaderboards)
- Membership tiers (cloud storage, fast download, and more)
- Ticket system (issue reporting and replies)
- Invite friends (both sides earn points)

### ☁️ Cloud Services
- Theme cloud backup (upload / restore / delete)
- Notification center (review / system / points notifications)
- Profile management

### 🔧 System
- Automatic version checks (startup + periodic polling)
- Forced update mechanism
- Global error boundary, crash auto-recovery
- Token expiry forces re-login
- Encrypted diagnostic log export
- Dark / light theme toggle
- Built-in Terms of Service page

## 🚀 Quick Start

1. **Download & install** — launch the app after installation.
2. **Register** — go to the Login / Register page and create an account.
3. **Browse the marketplace** — download themes you like, or create your own.
4. **Edit a theme** — drag widgets and adjust styles in the editor.
5. **Push to phone** — send the theme to your Android device via WebSocket.
